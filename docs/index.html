Classification 1. Advanced Classification (GIC / Head-Tail / Fisher-Jenks) zero2cartolab:geometric_interval_classification
▼
📐 Theoretical Formulation

Implements three complementary partition algorithms for skewed and non-normal urban data distributions. The Adaptive Geometric Interval Classification (GIC) fits a geometric progression to class breaks:

$$C_k = a \cdot r^k, \quad k \in \{0, 1, \dots, K\}$$ $$ ext{Objective:} \quad \min_{r} \sum_{k=1}^{K} \left( f_k - rac{n}{K} ight)^2$$

Head/Tail Breaks (Jiang, 2013) recursively partitions heavy-tailed data at the arithmetic mean $\mu_i$, retaining values where $x > \mu_i$ until the head proportion $\ge 40\%$. Fisher-Jenks minimizes the total within-class variance (Sum of Squared Deviations, $SSDW$).

⚙️ Algorithm Parameters
ParameterTypeDefaultDescription
INPUTVector Layer—Source polygon, line, or point layer.
FIELDField—Numeric field to classify.
METHODEnum (0=GIC, 1=Head/Tail, 2=Fisher-Jenks)0Classification strategy.
CLASSESInteger5Target number of classes (for GIC and Fisher-Jenks).
OUTPUTVector Layer[Create Temporary]Output layer with gic_class and gic_label fields.
💻 PyQGIS Execution Example
import processing

params = {
    'INPUT': 'path/to/land_values.gpkg|layername=parcels',
    'FIELD': 'unit_price_sqm',
    'METHOD': 0, # 0 = Adaptive GIC
    'CLASSES': 6,
    'OUTPUT': 'memory:classified_land_values'
}
result = processing.run('zero2cartolab:geometric_interval_classification', params)
QgsProject.instance().addMapLayer(result['OUTPUT'])
📚 Academic References
  • Jiang, B. (2013). Head/tail breaks: A new classification scheme for data with a heavy-tailed distribution. The Professional Geographer, 65(3), 482–494. doi:10.1080/00330124.2012.700499
  • Jenks, G. F. (1967). The data model concept in statistical mapping. International Yearbook of Cartography, 7, 186–190.
Thematic 2. Bivariate Choropleth Mapping zero2cartolab:bivariate_choropleth
▼
📐 Theoretical Formulation

Encodes two continuous spatial variables into an $N imes N$ matrix ($N \in \{3, 4\}$) by classifying each variable independently and mapping class coordinates $(i, j)$ to an interpolated RGB color:

$$\mathbf{C}(u, v) = (1-u)(1-v)\mathbf{C}_{00} + u(1-v)\mathbf{C}_{10} + (1-u)v\mathbf{C}_{01} + uv\mathbf{C}_{11}$$ $$ ext{where } u = rac{i-1}{N-1}, \quad v = rac{j-1}{N-1}, \quad i,j \in \{1, \dots, N\}$$
⚙️ Algorithm Parameters
ParameterTypeDefaultDescription
INPUTVector Layer—Source polygon layer.
FIELD_XField—First numeric variable (horizontal axis).
FIELD_YField—Second numeric variable (vertical axis).
MATRIX_SIZEInteger (3 or 4)3Matrix dimension ($3 imes3$ or $4 imes4$).
PALETTE_PRESETEnum0Color scheme (Pink-Blue, Purple-Green, Orange-Cyan, etc.).
OUTPUTVector Layer[Create Temporary]Output layer with bivar_x, bivar_y, bivar_class.
💻 PyQGIS Execution Example
import processing

params = {
    'INPUT': 'path/to/neighborhoods.gpkg',
    'FIELD_X': 'median_income',
    'FIELD_Y': 'tree_canopy_pct',
    'MATRIX_SIZE': 3,
    'PALETTE_PRESET': 0, # Pink - Blue
    'METHOD': 0, # 0 = Quantiles
    'OUTPUT': 'memory:bivariate_income_canopy'
}
res = processing.run('zero2cartolab:bivariate_choropleth', params)
QgsProject.instance().addMapLayer(res['OUTPUT'])
📚 Academic References
  • Brewer, C. A. (1994). Color use guidelines for mapping and visualization. Visualization in Modern Cartography, 123–147.
  • Elmqvist, N., et al. (2008). Z-ordering for scatterplot matrices. IEEE TVCG, 14(6), 1532–1539.

Cartogram 4. Continuous-Area Diffusion Cartogram zero2cartolab:compute_cartogram
▼
📐 Theoretical Formulation

Implements the Gastner & Newman (2004) diffusion-based density-equalizing algorithm. Polygons deform following the continuous velocity field $\mathbf{v}(\mathbf{r}, t)$ generated by spatial density gradients:

$$ abla^2 ho - rac{\partial ho}{\partial t} = 0, \quad \mathbf{v}(\mathbf{r}, t) = - rac{ abla ho}{ ho}$$ $$ rac{d\mathbf{r}}{dt} = \mathbf{v}(\mathbf{r}, t), \quad \mathbf{r}(0) = \mathbf{r}_0$$
⚙️ Algorithm Parameters
ParameterTypeDefaultDescription
INPUTPolygon Layer—Contiguous polygon layer.
FIELDField—Positive numeric variable to scale area to.
ITERATIONSInteger10Number of diffusion integration steps.
GRID_SIZEInteger128Underlying FFT / finite-difference resolution.
OUTPUTPolygon Layer[Create Temporary]Equalized cartogram layer.
📚 Academic References
  • Gastner, M. T., & Newman, M. E. (2004). Diffusion-based method for producing density-equalizing maps. PNAS, 101(20), 7499–7504. doi:10.1073/pnas.0400280101
Thematic 5. Hole-Aware Dot-Density Symbology zero2cartolab:dot_density
▼
📐 Theoretical Formulation

Scatters $N = \lfloor V_i / ext{DotValue} floor$ discrete point features inside each polygon $P_i$. Uses seeded rejection sampling within bounding boxes while respecting interior holes and multi-polygon boundaries.

$$N_i = \mathrm{round}\left( rac{V_i}{ ext{DOT\_VALUE}} ight), \quad p_k \in P_i \setminus igcup_{j} H_{i,j}$$
⚙️ Algorithm Parameters
ParameterTypeDefaultDescription
INPUTPolygon Layer—Source boundary layer.
FIELDField—Count field (e.g. population, households).
DOT_VALUEDouble100.0Value represented by 1 dot.
SEEDInteger42Random seed for reproducible placements.
OUTPUTPoint Layer[Create Temporary]Output scattered point layer.
Cartogram & Aggregation 6. Hexagonal Binning & Spatial Aggregation zero2cartolab:hexbin_aggregate
▼
📐 Theoretical Formulation

Constructs a regular pointy-top hexagonal tessellation over the point extent and aggregates counts, sums, and averages using axial coordinate hashing $(q, r)$:

$$q = rac{\sqrt{3}/3 \cdot x - 1/3 \cdot y}{R}, \quad r = rac{2/3 \cdot y}{R}$$ $$ ext{Area}_{ ext{hex}} = rac{3\sqrt{3}}{2} R^2$$

Layout & Reference 8. Visual-Center Label Points (Polylabel) zero2cartolab:label_points
▼
📐 Theoretical Formulation

Calculates the Pole of Inaccessibility—the interior point furthest from any polygon boundary—using an iterative quadtree spatial search (Garcia-Castellanos & Lombardo, 2007):

$$p^* = rg\max_{p \in P} \min_{e \in \partial P} \|p - e\|$$
Classification 9. Statistical Normalization & Location Quotient zero2cartolab:normalize_field
▼
📐 Theoretical Formulation

Provides 6 standard statistical transformations for comparative mapping:

$$z = rac{x - \mu}{\sigma}, \quad z_{ ext{robust}} = rac{x - ext{median}}{1.4826 \cdot ext{MAD}}, \quad ext{LQ} = rac{e_i / e_{ ext{total}}}{E_i / E_{ ext{total}}}$$
Thematic 10. Flannery Perceptual Proportional Symbols zero2cartolab:proportional_symbols
▼
📐 Theoretical Formulation

Compensates for human underestimation of circular visual areas using Flannery's psychophysical exponent ($0.57$ instead of geometric $0.50$):

$$R_i = R_0 \cdot \left( rac{V_i}{V_0} ight)^{0.5716}$$
  • Flannery, J. J. (1971). The relative effectiveness of standard and modified graduated circles in statistical distribution maps. The Canadian Cartographer, 8(2), 96–109.

Thematic 13. Value-by-Alpha (VbA) Uncertainty Symbology zero2cartolab:value_by_alpha
▼
📐 Theoretical Formulation

Modulates the alpha (transparency) channel based on statistical uncertainty or sample size, preventing low-confidence estimates from dominating map visual hierarchy:

$$lpha_i = lpha_{\min} + (255 - lpha_{\min}) \cdot \left( rac{R_i - R_{\min}}{R_{\max} - R_{\min}} ight)^\gamma$$
2.5D Massing 14. Architectural 2.5D Building Extrusion zero2cartolab:building_25d_style
▼
📐 Theoretical Formulation

Calculates oblique roof offsets, stepped floor bands, and trigonometric wall shading based on solar azimuth $ heta_{ ext{sun}}$ and elevation angle $\phi$:

$$\Delta x = H_i \cdot \cos( heta_{ ext{view}}), \quad \Delta y = H_i \cdot \sin( heta_{ ext{view}})$$ $$I_{ ext{wall}} = I_{ ext{ambient}} + I_{ ext{direct}} \cdot \max(0, \cos( heta_{ ext{wall}} - heta_{ ext{sun}}))$$
System Design

Architectural Principles & Robustness

Engineered for stability across both QGIS 3.x LTR and QGIS 4.x next-generation releases.

📦 Pure Python Core Math

All core computational engines (classification, bivariate interpolation, geometry math, CVD matrices) are written in pure Python/NumPy with zero external binary or C-extension requirements.

⚡ Headless Processing Provider

Every algorithm runs headlessly inside the QGIS Processing framework, enabling full integration with Graphical Modeler workflows, Python CLI scripts, and automated batch processing.

🧪 Dual-Runtime Verification

68 comprehensive end-to-end unit and integration tests run continuously across both QGIS 3.44 LTR and QGIS 4.2 runtimes, ensuring zero regressions on Qt5 and Qt6.

🛡️ Color Accessibility Guard

Embedded Machado/Brettel colorblindness simulation engine and automated WCAG 2.1 contrast ratio calculators prevent illegible or inaccessible cartographic outputs.
